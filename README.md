# Аудиоредактор

Сайт для обработки звука прямо в браузере. Файлы никуда не загружаются, всё считается на вашем компьютере. Разделы переключаются в меню справа.

## Аудиоредактор
- обрезка выделенного куска, реверс и прослушивание (повтор, пробел, клик по дорожке)
- скорость и высота звука от ×0.02 до ×50 (независимо друг от друга), громкость от ×0.1 до ×10
- эффекты: эхо, робот, лилипут, великан, рация, зал (с регулировкой силы)
- затухание в начале и в конце (ползунки или белые кружки на дорожке, как в видеоредакторах)
- склейка нескольких файлов с выбором порядка и плавным переходом
- сохранение в MP3 (128, 192, 256, 320 кбит/с) или в WAV без потерь, имя файла можно поменять

## Звукозапись
- запись с выбранного микрофона
- шумоподавление: встроенное в браузер (включается при записи) и ползунок, который убирает тихий фон
- тон и громкость: громкость записи, низкие и высокие частоты, фильтр низкого гула
- компрессор: включение, три готовых варианта (мягкий, голос, сильный), сила и усиление
- эффекты: эхо, робот, лилипут, великан, рация, зал (с регулировкой силы)
- обрезка записи, прослушивание и скачивание в MP3 с переименованием файла

## Структура
- `index.html` весь сайт (HTML, CSS и JavaScript в одном файле)
- `.nojekyll` говорит GitHub Pages отдавать файлы как есть

## Запуск у себя
Откройте `index.html` двойным кликом (лучше Chrome или Edge).

## Микрофон
Браузер даёт доступ к микрофону только на страницах с https (GitHub Pages подходит) или у локального файла. Разрешение спросит сам браузер.

## Публикация на GitHub Pages
1. Создайте на GitHub публичный репозиторий, например `audio-editor`.
2. Загрузите в него файлы из этой папки (Add file → Upload files). Загружайте содержимое папки, а не саму папку.
3. Откройте Settings → Pages. В пункте Source выберите Deploy from a branch, ветку `main` и папку `/ (root)`, нажмите Save.
4. Через минуту-две сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/audio-editor/`.

## Обновления
Заменяйте `index.html` новой версией и делайте commit. Сайт обновится сам через минуту-две.

## MP3
MP3 кодирует библиотека lamejs (LAME, лицензия LGPL, сайт проекта: lame.sourceforge.net). Она подключается отдельным файлом с cdnjs, поэтому для MP3 нужен интернет. Если библиотека не загрузилась, сайт сохранит WAV.
